# 🚀 Task Assistant

A full-stack **MERN-based personal productivity platform** designed to help users manage tasks, plan deadlines, organize work visually, and build better daily systems.

Built as a real product for personal use + portfolio growth.

---

# 🌟 Project Vision

Task Assistant is not just a todo app.

It is being built as a **personal productivity Assistant ** where users can:

- Manage daily work
- Track deadlines
- Track habits and progress
- Plan visually using calendar
- Build consistency
- Improve execution habits
